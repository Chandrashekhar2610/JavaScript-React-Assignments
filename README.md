# JavaScript & React Assignments

Six assignments, deployed with GitHub Pages.

| # | Project | Type |
|---|---------|------|
| 1 | JS Calculator | HTML/CSS/JS |
| 2 | Todo List | HTML/CSS/JS |
| 3 | Form Validation | HTML/CSS/JS |
| 4 | React Profile Card | React + Vite |
| 5 | React Controlled Form | React + Vite |
| 6 | React Counter | React + Vite |

## Run locally
- Assignments 1-3: open `index.html` in the folder.
- Assignments 4-6:
  ```bash
  cd Assignment-4-React-Profile-Card
  npm install
  npm run dev
  ```

## Deploy (GitHub Pages)
1. Push to the `main` branch.
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. Open the **Actions** tab and wait for "Deploy All Six Assignments" to finish.
4. Site: `https://<your-username>.github.io/<repo-name>/`
